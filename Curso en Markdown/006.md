<h2 style="margin: 36px 0 16px 0; font-size: 22px; font-weight: 700; color: var(--pb-fg-0); border-left: 6px solid var(--pb-blue); padding-left: 14px; line-height: 1.3;">Concepto</h2>
<p style="margin: 0 0 16px 0; font-size: 14px; color: var(--pb-fg-1); line-height: 1.6;">PostgreSQL guarda texto con tres tipos. CHAR(n) guarda exactamente n caracteres y rellena con espacios si el valor es más corto. VARCHAR(n) guarda hasta n caracteres sin relleno. TEXT no tiene límite declarado (hasta 1 GB). Si un valor supera el límite n de CHAR o VARCHAR, PostgreSQL lo rechaza con un error: no lo corta.</p>

<div style="display: grid; grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)); gap: 16px; width: 100%; box-sizing: border-box; align-items: stretch;">
  <div style="background: var(--pb-bg-1); border-top: 4px solid var(--pb-green); border-radius: 8px; padding: 18px 22px; width: 100%; height: 100%; box-sizing: border-box; display: flex; flex-direction: column; justify-content: flex-start;">
    <h3 style="margin: 0 0 8px 0; font-size: 16px; font-weight: 700; color: var(--pb-green-strong);">CHAR(n)</h3>
    <p style="margin: 0; font-size: 13px; color: var(--pb-fg-1); line-height: 1.6;">Largo fijo. Guarda exactamente n caracteres; si el valor es más corto, se rellena con espacios a la derecha.</p>
  </div>
  <div style="background: var(--pb-bg-1); border-top: 4px solid var(--pb-blue); border-radius: 8px; padding: 18px 22px; width: 100%; height: 100%; box-sizing: border-box; display: flex; flex-direction: column; justify-content: flex-start;">
    <h3 style="margin: 0 0 8px 0; font-size: 16px; font-weight: 700; color: var(--pb-blue-strong);">VARCHAR(n)</h3>
    <p style="margin: 0; font-size: 13px; color: var(--pb-fg-1); line-height: 1.6;">Largo variable con tope de n caracteres. Sin relleno de espacios.</p>
  </div>
  <div style="background: var(--pb-bg-1); border-top: 4px solid var(--pb-purple); border-radius: 8px; padding: 18px 22px; width: 100%; height: 100%; box-sizing: border-box; display: flex; flex-direction: column; justify-content: flex-start;">
    <h3 style="margin: 0 0 8px 0; font-size: 16px; font-weight: 700; color: var(--pb-purple-strong);">TEXT</h3>
    <p style="margin: 0; font-size: 13px; color: var(--pb-fg-1); line-height: 1.6;">Largo variable sin tope declarado (hasta 1 GB). No tiene límite arbitrario.</p>
  </div>
</div>

<h2 style="margin: 36px 0 16px 0; font-size: 22px; font-weight: 700; color: var(--pb-fg-0); border-left: 6px solid var(--pb-teal); padding-left: 14px; line-height: 1.3;">Para qué sirve</h2>
<p style="margin: 0 0 12px 0; font-size: 14px; color: var(--pb-fg-1); line-height: 1.6;">Casos de uso en análisis de datos:</p>

<div style="display: grid; grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)); gap: 16px; width: 100%; box-sizing: border-box; align-items: stretch;">
  <div style="background: var(--pb-bg-1); border-top: 4px solid var(--pb-green); border-radius: 8px; padding: 18px 22px; width: 100%; height: 100%; box-sizing: border-box; display: flex; flex-direction: column; justify-content: flex-start;">
    <span style="display: inline-block; background: var(--pb-green-tint); color: var(--pb-green-strong); padding: 4px 10px; border-radius: 6px; font-size: 12px; font-weight: 600; margin-bottom: 8px; align-self: flex-start;">1. CHAR(n)</span>
    <p style="margin: 0; font-size: 13px; color: var(--pb-fg-1); line-height: 1.6;">Códigos de largo fijo (código de país ISO, SKU, código de envío).</p>
  </div>
  <div style="background: var(--pb-bg-1); border-top: 4px solid var(--pb-blue); border-radius: 8px; padding: 18px 22px; width: 100%; height: 100%; box-sizing: border-box; display: flex; flex-direction: column; justify-content: flex-start;">
    <span style="display: inline-block; background: var(--pb-blue-tint); color: var(--pb-blue-strong); padding: 4px 10px; border-radius: 6px; font-size: 12px; font-weight: 600; margin-bottom: 8px; align-self: flex-start;">2. VARCHAR(n)</span>
    <p style="margin: 0; font-size: 13px; color: var(--pb-fg-1); line-height: 1.6;">Nombres, ciudades, categorías y estados con un largo máximo razonable, que luego se usan para agrupar y filtrar.</p>
  </div>
  <div style="background: var(--pb-bg-1); border-top: 4px solid var(--pb-purple); border-radius: 8px; padding: 18px 22px; width: 100%; height: 100%; box-sizing: border-box; display: flex; flex-direction: column; justify-content: flex-start;">
    <span style="display: inline-block; background: var(--pb-purple-tint); color: var(--pb-purple-strong); padding: 4px 10px; border-radius: 6px; font-size: 12px; font-weight: 600; margin-bottom: 8px; align-self: flex-start;">3. TEXT</span>
    <p style="margin: 0; font-size: 13px; color: var(--pb-fg-1); line-height: 1.6;">Comentarios, descripciones, observaciones y logs de largo impredecible, que se analizan como texto libre.</p>
  </div>
</div>

<h2 style="margin: 36px 0 16px 0; font-size: 22px; font-weight: 700; color: var(--pb-fg-0); border-left: 6px solid var(--pb-amber); padding-left: 14px; line-height: 1.3;">Sintaxis general</h2>
<p style="margin: 0 0 12px 0; font-size: 14px; color: var(--pb-fg-1); line-height: 1.6;">Al definir una columna (CREATE TABLE se explica más adelante):</p>
<pre style="background: var(--pb-bg-2); border: 1px solid var(--pb-border); border-radius: 8px; padding: 14px 18px; max-width: 100%; overflow-x: auto; white-space: pre; margin: 0 0 16px 0; font-size: 13px; line-height: 1.6; color: var(--pb-fg-0); font-family: 'Consolas', 'Monaco', monospace;"><code style="background: none; padding: 0; color: var(--pb-fg-0);">nombre_columna CHAR(n)
nombre_columna VARCHAR(n)
nombre_columna TEXT</code></pre>

<div style="background: var(--pb-bg-1); border-left: 4px solid var(--pb-green); border-radius: 8px; padding: 14px 18px; margin-bottom: 24px;">
  <ul style="margin: 0; padding-left: 20px; font-size: 13px; color: var(--pb-fg-1); line-height: 1.8;">
    <li><strong style="color: var(--pb-fg-0);">nombre_columna</strong>: el nombre de la columna.</li>
    <li><strong style="color: var(--pb-fg-0);">CHAR(n)</strong>: largo fijo; si el valor tiene menos de n caracteres, se completa con espacios a la derecha.</li>
    <li><strong style="color: var(--pb-fg-0);">VARCHAR(n)</strong>: largo variable con tope de n caracteres.</li>
    <li><strong style="color: var(--pb-fg-0);">TEXT</strong>: largo variable sin tope declarado.</li>
    <li><strong style="color: var(--pb-fg-0);">n</strong>: cantidad máxima de caracteres (no de bytes). Un acento o una ñ cuentan como un carácter.</li>
    <li>Los valores de texto se escriben entre comillas simples: <code style="background: var(--pb-bg-3); padding: 2px 6px; border-radius: 4px; font-size: 12px; color: var(--pb-fg-0);">'Lima'</code>.</li>
  </ul>
</div>
