<!-- CONCEPTO -->
<h2 style="margin: 36px 0 12px; padding-left: 14px; border-left: 6px solid var(--pb-blue); font-size: 1.4rem; font-weight: 700; color: var(--pb-fg-0);">Concepto</h2>
<p style="margin: 0 0 16px; color: var(--pb-fg-1);">BOOLEAN es el tipo de dato que representa verdadero, falso o desconocido. PostgreSQL lo almacena como un valor booleano y DBeaver lo muestra como <code style="background: var(--pb-bg-3); padding: 2px 6px; border-radius: 4px; font-size: 0.9em;">true</code>, <code style="background: var(--pb-bg-3); padding: 2px 6px; border-radius: 4px; font-size: 0.9em;">false</code> o <code style="background: var(--pb-bg-3); padding: 2px 6px; border-radius: 4px; font-size: 0.9em;">NULL</code>. No es texto: no está pensado para guardar "Sí", "No", "S/N" ni descripciones libres.</p>

<h2 style="margin: 36px 0 12px; padding-left: 14px; border-left: 6px solid var(--pb-red); font-size: 1.4rem; font-weight: 700; color: var(--pb-fg-0);">BOOLEAN tiene tres valores, no dos</h2>
<p style="margin: 0 0 16px; color: var(--pb-fg-1);">Esa es la diferencia clave frente a un <code style="background: var(--pb-bg-3); padding: 2px 6px; border-radius: 4px; font-size: 0.9em;">CHAR(1)</code> con <code style="background: var(--pb-bg-3); padding: 2px 6px; border-radius: 4px; font-size: 0.9em;">'S'</code>/<code style="background: var(--pb-bg-3); padding: 2px 6px; border-radius: 4px; font-size: 0.9em;">'N'</code>: el tipo BOOLEAN restringe el dominio a <code style="background: var(--pb-bg-3); padding: 2px 6px; border-radius: 4px; font-size: 0.9em;">TRUE</code>, <code style="background: var(--pb-bg-3); padding: 2px 6px; border-radius: 4px; font-size: 0.9em;">FALSE</code> y <code style="background: var(--pb-bg-3); padding: 2px 6px; border-radius: 4px; font-size: 0.9em;">NULL</code>. Un <code style="background: var(--pb-bg-3); padding: 2px 6px; border-radius: 4px; font-size: 0.9em;">CHAR(1)</code>, en cambio, permite cualquier letra.</p>
