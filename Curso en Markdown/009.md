<h2 style="margin: 32px 0 16px 0; padding-left: 14px; border-left: 6px solid var(--pb-blue); font-size: 22px; color: var(--pb-fg-0); font-weight: 700; line-height: 1.3;">Concepto</h2>

<div style="background: var(--pb-bg-1); border: 1px solid var(--pb-border); border-top: 4px solid var(--pb-blue); border-radius: 10px; padding: 18px 22px; margin: 0 0 24px 0; width: 100%; box-sizing: border-box; display: flex; flex-direction: column; justify-content: flex-start; box-shadow: var(--pb-shadow-sm);">
  <p style="margin: 0 0 14px 0; color: var(--pb-fg-0); font-size: 14.5px;">NULL no es cero, ni texto vacío, ni FALSE: es la <strong style="color: var(--pb-blue-strong);">ausencia de dato</strong> o un <strong style="color: var(--pb-blue-strong);">dato desconocido</strong>. Por eso cualquier operación en la que participa devuelve NULL, y la lógica deja de tener dos valores para tener tres: <strong style="color: var(--pb-purple-strong);">verdadero, falso y desconocido</strong>.</p>
  <div style="background: var(--pb-bg-2); border-left: 4px solid var(--pb-teal); border-radius: 6px; padding: 12px 14px; font-size: 13.5px; color: var(--pb-fg-1);">
    En DBeaver las celdas con NULL se muestran como <code style="background: var(--pb-bg-3); padding: 2px 6px; border-radius: 4px; font-family: 'SF Mono', Consolas, monospace; font-size: 12.5px; color: var(--pb-fg-0);">(null)</code> en color gris. Ese texto <strong style="color: var(--pb-fg-0);">NO</strong> es la cadena <code style="background: var(--pb-bg-3); padding: 2px 6px; border-radius: 4px; font-family: 'SF Mono', Consolas, monospace; font-size: 12.5px; color: var(--pb-fg-0);">'null'</code>: es la representación visual de la ausencia de dato.
  </div>
