<!-- SINTAXIS -->
<h2 style="border-left:6px solid var(--pb-amber);padding-left:14px;margin:36px 0 16px 0;font-size:19px;line-height:1.3;color:var(--pb-fg-0);">Sintaxis general</h2>
<pre><code>DATE 'YYYY-MM-DD'                     -- año, mes y día
TIME 'HH:MI:SS'                       -- hora del día, hasta 24:00:00
TIMESTAMP 'YYYY-MM-DD HH:MI:SS'       -- fecha y hora sin zona horaria
TIMESTAMPTZ 'YYYY-MM-DD HH:MI:SS+HH'  -- fecha, hora y offset respecto a UTC</code></pre>

<div style="background:var(--pb-green-tint);border-left:4px solid var(--pb-green);border-radius:10px;padding:14px 18px;margin-top:16px;margin-bottom:24px;">
  <ul style="margin:0;padding-left:18px;font-size:13px;color:var(--pb-fg-1);">
    <li style="margin-bottom:4px;">DATE no incluye hora.</li>
    <li style="margin-bottom:4px;">TIME no incluye fecha.</li>
    <li style="margin-bottom:4px;">TIMESTAMP no sabe en qué zona se registró.</li>
    <li style="margin-bottom:4px;">TIMESTAMPTZ sí conserva el instante: si guardas 10:00+01 y 04:00-05, ambos son las 09:00 UTC y representan el mismo momento.</li>
    <li>Los rangos son amplios: DATE admite valores como 'infinity'; TIME llega hasta '24:00:00'; TIMESTAMP y TIMESTAMPTZ admiten fechas lejanas y también 'infinity'.</li>
  </ul>
</div>

    <strong style="font-size:11px;text-transform:uppercase;letter-spacing:.06em;color:var(--pb-amber-strong);">Aclaración sobre 'infinity'</strong>
    <ul style="margin:6px 0 0 0;padding-left:18px;font-size:13px;color:var(--pb-fg-1);">
      <li style="margin-bottom:4px;">'infinity' es un valor especial de PostgreSQL, no una fecha real del calendario.</li>
      <li style="margin-bottom:4px;">Lo aceptan DATE, TIMESTAMP y TIMESTAMPTZ; TIME no lo admite porque su máximo es '24:00:00'.</li>
      <li style="margin-bottom:4px;">También existe '-infinity' para representar el extremo opuesto.</li>
      <li style="margin-bottom:4px;">En comparaciones, 'infinity' es mayor que cualquier fecha finita y '-infinity' es menor que cualquiera.</li>
      <li style="margin-bottom:4px;">Sirve para rangos abiertos, por ejemplo <code>valid_to DATE 'infinity'</code> o <code>desde TIMESTAMPTZ '-infinity'</code>.</li>
      <li style="margin-bottom:4px;"><code>isfinite(valor)</code> devuelve false para estos valores; es útil para filtrarlos o detectarlos.</li>
      <li style="margin-bottom:4px;">Al mostrarlo por pantalla o al castearlo a texto aparece literalmente como 'infinity'.</li>
      <li style="margin-bottom:4px;">No es lo mismo que NULL: NULL significa "desconocido"; 'infinity' significa "sin límite" y se puede ordenar y comparar.</li>
      <li>Algunos drivers o clientes pueden no manejarlo bien; conviene documentarlo si se usa en modelos de datos.</li>
